# Simple Ecommerce Flutter App: Developed with Generative AI Assistance

## Project Overview

This repository hosts a simple e-commerce mobile application built with Flutter, designed with a modern Material Design user interface. The project aims to demonstrate a clean, intuitive, and user-friendly shopping experience.

## Generative AI in Development

This project leverages Generative AI (GenAI) tools and methodologies to enhance various stages of its development lifecycle. Our approach integrates AI not merely as a code generator, but as a powerful assistant for:

*   **Code Comprehension:** Utilizing AI to understand existing codebases, complex functions, and algorithms.
*   **Documentation:** Generating and improving comprehensive documentation for code, APIs, and user guides.
*   **Debugging:** Assisting in tracing error messages, analyzing stack traces, and identifying performance bottlenecks.
*   **Testing:** Aiding in understanding what to test, improving test quality, and guiding Test-Driven Development (TDD) practices.
*   **Refactoring & Enhancement:** Supporting code refactoring, improving readability, and implementing design patterns.
*   **Learning & Skill Development:** Facilitating the learning of new programming languages, frameworks, and libraries.

This integration aims to boost productivity, ensure code quality, and accelerate the learning curve for developers working on the project.

## Features

*   User authentication (sign up, sign in)
*   Product catalog
*   Shopping cart
*   Checkout process
*   User profile management
*   Real-time chat with store

## Getting Started

To get started with this project, you will need to have Flutter installed on your machine. You can find instructions on how to install Flutter [here](https://flutter.dev/docs/get-started/install).

Once you have Flutter installed, you can clone this repository and run the following command to install the dependencies:

```bash
flutter pub get
```

After the dependencies are installed, you can run the application using the following command:

```bash
flutter run
```

## Backend

This project currently uses a Spring Boot REST API as its backend. The source code for the backend can be found in the `RestApi` directory.
